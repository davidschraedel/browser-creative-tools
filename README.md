# Browser Creative Tools

A few small "vibed" tools that run in the browser.

My favorite Figma-based plugin for vectorizing an image disappeared, so I built my own tool. It inspired other ideas, and now this repository houses all such chaotic creative tools.

## Tools

- **Pixel Shuffle** (`pixel-shuffle.html`): randomly swap pixels in an image.
- **Shape Shuffle** (`pixel-cluster-shuffle.html`): shuffle clusters of pixels in an image.
- **Layer Vectorizer** (`layer-vectorizer.html`): turn an image into layered SVG shapes.

## Usage

Clone the repo, then open `index.html` in a browser. No build step or dependencies.

```
git clone https://github.com/davidschraedel/browser-creative-tools.git
cd browser-creative-tools
open index.html
```
